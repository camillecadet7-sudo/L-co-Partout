# L'éco partout

Site web interactif sur l'actualité économique dans le monde, mis à jour chaque semaine.
Une planète 3D (jour/nuit en temps réel) sur laquelle on clique sur un pays pour lire ses articles.

Site statique : un seul fichier `index.html` (images, données et articles inclus).
Aucune clé, aucun serveur, aucune étape de build.

## Déploiement
Vercel : importer ce dépôt, framework « Other », laisser les réglages par défaut (pas de commande de build, dossier racine `./`).
